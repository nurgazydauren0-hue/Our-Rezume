    Справка: HTTP-методы и коды ответа

    HTTP-методы

    GET — получить данные. POST — создать данные. PUT — полностью заменить данные. PATCH — частично изменить данные. DELETE — удалить данные.

    Категории статусов

    1xx — информационные сообщения; 2xx — успешные запросы; 3xx — перенаправления; 4xx — ошибка клиента; 5xx — ошибка сервера.

    Основные коды ответа

    • 200 OK — запрос успешно выполнен; 201 Created — объект создан; 204 No Content — запрос успешный, но данных нет.
    • 301 Moved Permanently — ресурс навсегда перенесён; 302 Found — временное перенаправление; 304 Not Modified — ресурс не изменился.
    • 400 Bad Request — неправильный запрос; 401 Unauthorized — нет авторизации; 403 Forbidden — доступ запрещён; 404 Not Found — ресурс не найден; 405 Method Not Allowed — HTTP-метод запрещён; 429 Too Many Requests — слишком много запросов.
    • 500 Internal Server Error — ошибка сервера; 502 Bad Gateway — ошибка при взаимодействии серверов; 503 Service Unavailable — сервер временно недоступен.

    В Chrome откройте DevTools → Network → Fetch/XHR, затем выполните действия со списком. В колонке Method видны GET, POST, PATCH и DELETE. PUT приведён для справки.
